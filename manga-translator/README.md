# МангаПеревод

Браузерный автопереводчик манги, манхвы и комиксов на русский язык.
Загружаете главу → vision-модель находит и распознаёт текст → текстовая модель переводит всю главу сразу
(с учётом контекста, заметок о персонажах и глоссария) → сайт стирает оригинал и вписывает перевод →
доводка во встроенном редакторе → экспорт ZIP.

Сервера нет: всё работает в браузере пользователя, ключи API хранятся в его localStorage,
проекты — в IndexedDB. Запросы идут напрямую к выбранному сервису ИИ (OpenRouter, DeepSeek или любой OpenAI-совместимый).

## Возможности

- Языки оригинала: японский, китайский, корейский, английский → русский.
- Манга (страницы, чтение справа налево) и вебтуны (длинные полосы режутся на куски по пустым местам между кадрами).
- Раздельный выбор модели для распознавания и для перевода; проверка подключения, загрузка списка моделей.
- Контекстный перевод: сначала распознаётся вся глава, затем текст переводится крупными пачками с хвостом предыдущего перевода.
- Глоссарий проекта и общие глоссарии тайтла, импорт/экспорт CSV, автопроверка использования терминов (с учётом окончаний) и автоисправление, подсказка терминов моделью.
- Очистка без нейросети: поиск пузыря заливкой фона, стирание букв внутри него; для сложного фона — диффузионное заполнение.
- Вставка текста: выбор лучшей области внутри пузыря под конкретный перевод, автоподбор размера, переносы по слогам, выравнивание строк.
- Редактор: виды «оригинал / очищено / перевод», перемещение и изменение рамок, новые блоки, кисть-заливка, кисть «вернуть оригинал», пипетка, стили (9 шрифтов с кириллицей + свои), обводка, поворот, отмена.
- Вкладка «Текст»: вся глава в таблице «оригинал → перевод», правка, порядок реплик, перевод отдельной строки заново.
- Экспорт ZIP: переведённые страницы, чистые страницы, текст (TXT/JSON); резервная копия проекта для передачи коллеге.
- Демо-проект без ключа и встроенное руководство.

## Запуск и сборка

Нужен Node.js 18+.

```bash
npm install
npm run build      # результат в папке dist/
npm run dev        # локально: http://localhost:5173 с пересборкой при изменениях
```

Папку `dist/` можно открыть любым статическим сервером (`npx serve dist`) или выложить на хостинг.

## Публикация на GitHub Pages (бесплатно)

1. Создайте репозиторий на GitHub и загрузите в него этот проект.
2. Settings → Pages → Source: **GitHub Actions**.
3. Сделайте push в ветку `main` — workflow `.github/workflows/deploy.yml` соберёт и опубликует сайт
   по адресу `https://<логин>.github.io/<репозиторий>/`.

Подойдут и Cloudflare Pages / Netlify / Vercel: команда сборки `npm run build`, папка `dist`.

## Прокси для DeepSeek (если нужен)

Если браузер не пускает запросы к API напрямую (ошибка CORS), разверните `proxy/worker.js`
на Cloudflare Workers (бесплатно) и укажите его адрес в «Настройках API». Инструкция — в комментарии в файле.

## Структура

```
src/
  lib/            логика без интерфейса
    llm.ts        запросы к OpenAI-совместимому API, повторы, разбор JSON
    ocr.ts        нарезка длинных страниц и распознавание vision-моделью
    translate.ts  контекстный перевод, глоссарий, проверка терминов
    clean.ts      очистка текста и поиск области внутри пузыря
    typeset.ts    подбор шрифта, переносы, отрисовка
    pipeline.ts   этапы обработки
    export.ts     ZIP и резервные копии
    db.ts         IndexedDB
    demo.ts       демо-страницы (рисуются в браузере)
  components/     интерфейс на React
test/             генератор тестовых страниц и сквозной тест (Playwright, API подменяется)
proxy/worker.js   CORS-прокси для Cloudflare Workers
```

## Тест

`test/make_pages.py` рисует синтетические страницы с известными координатами текста,
`test/e2e.py` проходит весь цикл в Chromium с подменённым API и сохраняет скриншоты:

```bash
python3 test/make_pages.py /tmp/pages
npx serve dist -l 8765 &
python3 test/e2e.py /tmp/pages http://localhost:8765/ /tmp/shots
```
